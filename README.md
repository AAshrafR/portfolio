## 📄 CV PDF Setup

Place your PDF resume into the `assets/` folder named:
```
assets/Abdelmasih_Ashraf_CV.pdf
```
Both the navigation bar "CV 📄" button and the Hero "Download CV" button automatically link to this file for instant viewing and downloading.

## 🚀 Run Locally

1. Simply double-click `index.html` to open it in any modern browser.
2. Alternatively, in VS Code, right-click `index.html` and choose **"Open with Live Server"**.

---

## 🌐 Deploy to GitHub Pages (Free)

1. Create a repository on GitHub (e.g., `portfolio` or `username.github.io`).
2. Push this project to the `main` branch:
3. In GitHub, navigate to **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, select branch `main` and folder `/ (root)`.
5. Click **Save**. Your site will be live within seconds!
